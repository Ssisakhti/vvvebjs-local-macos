# VvvebJs Local for macOS

ویرایش دیداری فایل HTML روی مک، با رابط فارسی و نسخهٔ پشتیبان خودکار.

این پروژه بر پایهٔ [VvvebJs 2.0.9](https://github.com/givanz/VvvebJs/tree/2.0.9) ساخته شده است. کد و راهنمای اصلی در این مخزن حفظ شده‌اند. این نسخه، محصول رسمی سازندهٔ VvvebJs نیست.

## امکانات

- صفحهٔ شروع فارسی، چیدمان راست‌به‌چپ، ورود فایل و پوشه با کشیدن و رها کردن، و جست‌وجوی فایل‌های اخیر.
- ویرایش فایل اصلی با گزینهٔ «باز کردن فایل اصلی» یا منوی Open With مک.
- نگهداری نسخهٔ اولیه و ۲۰ نسخهٔ اخیر پیش از تغییر.
- پیش‌نمایش، دریافت و بازیابی نسخه‌ها از داخل ویرایشگر.
- توقف ذخیره اگر فایل در برنامهٔ دیگری یا پنجرهٔ دیگری تغییر کرده باشد.
- ساخت برنامهٔ مک با آیکون HTML، پشتیبانی از دوبار کلیک و ثبت در منوی Open With.
- اجرای محلی روی `127.0.0.1`؛ بدون نیاز به PHP یا نصب بسته‌های npm.

## نصب

پیش‌نیازها: macOS، Git، Python 3.9 یا بالاتر، Node.js 22 یا بالاتر و Google Chrome. برای ساخت برنامه، ابزار `osacompile` مک باید در دسترس باشد.

```sh
git clone --recurse-submodules https://github.com/Ssisakhti/vvvebjs-local-macos.git ~/Applications/VvvebJs
cd ~/Applications/VvvebJs
python3 install-macos.py --desktop
```

اگر پوشه یا برنامهٔ VvvebJs از قبل وجود دارد، یک مسیر تازه انتخاب کنید. نصب‌کننده، برنامهٔ موجود را بازنویسی نمی‌کند:

```sh
python3 install-macos.py --output ~/Applications/VvvebJs-Test.app
```

روی برنامهٔ ساخته‌شده دوبار کلیک کنید. برنامه، سرویس محلی را اجرا می‌کند و صفحهٔ شروع را در Chrome باز می‌کند. پوشهٔ کد را پس از ساخت برنامه جابه‌جا نکنید؛ برای مسیر تازه، راه‌انداز را دوباره بسازید.

اجرای مستقیم بدون ساخت برنامه نیز ممکن است:

```sh
python3 local-launch.py
```

برای دریافت زیپ از GitHub، پس از استخراج باید زیرماژول `demo/landing` را هم دریافت کنید. استفاده از دستور clone بالا، این کار را انجام می‌دهد.

## ذخیرهٔ فایل

- **باز کردن فایل اصلی یا Open With:** دکمهٔ Save فایل اصلی را تغییر می‌دهد. نام و مسیر مقصد پایین ویرایشگر نمایش داده می‌شود.
- **ورود کپی یا کشیدن و رها کردن:** فایل‌ها در `workspace/` کپی می‌شوند. Save همان کپی را تغییر می‌دهد.
- **نسخه‌های پشتیبان:** نسخه‌ها در `local-backups/documents/` نگهداری می‌شوند. پنل پشتیبان، امکان نمایش پوشه در Finder را دارد.

پشتیبان‌ها شامل HTML و فایل‌های همراه شناسایی‌شده در همان پوشه و زیرپوشه‌های آن هستند. مسیرهای بیرون از پوشهٔ فایل، فایل‌های مخفی، پیوندهای نمادین و منابع اینترنتی در پشتیبان کپی نمی‌شوند. برای هر نسخه، سقف ۶۰ مگابایت و ۱۰۰۰ فایل وجود دارد. این قابلیت جایگزین پشتیبان‌گیری کامل از دستگاه نیست.

اگر ساخت پشتیبان شکست بخورد، ذخیره متوقف می‌شود. پیش از بازیابی هم از وضعیت فعلی نسخه گرفته می‌شود. تصویرهای تازه هنگام ذخیره در یک پوشهٔ همراه با نام `<filename>.vvveb-assets` کنار فایل مقصد قرار می‌گیرند.

## داده‌های محلی

فایل‌های شخصی، سابقهٔ فایل‌ها، توکن راه‌انداز، گزارش اجرا و پشتیبان‌ها در `.gitignore` قرار دارند. آن‌ها بخشی از این مخزن عمومی نیستند. پوشهٔ `samples/` فقط دادهٔ آزمایشی دارد. هنگام اولین اجرا، نمونه‌ها به `workspace/` کپی می‌شوند.

درگاه پیش‌فرض `8787` است. اگر نسخهٔ دیگری از برنامه روی همین درگاه اجرا می‌شود، آن را متوقف کنید یا برای اجرای مستقیم از یک درگاه دیگر استفاده کنید:

```sh
VVVEB_PORT=8788 python3 local-launch.py
```

اگر Node.js در مسیر معمول نصب نشده است، مسیر آن را با متغیر `VVVEB_NODE` تعیین کنید.

## بررسی عملکرد

```sh
node .local-tests/documents.cjs
```

این آزمون‌ها با فایل‌های موقت اجرا می‌شوند: ذخیرهٔ اصل، نسخهٔ اولیه، نگهداری ۲۰ نسخه، بازیابی، تغییر بیرونی، دو پنجرهٔ هم‌زمان، تصویرهای همراه، خطای پشتیبان و برگشت از خطای ذخیره.
